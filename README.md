# Pop Culture Makhana Snacks 🍿

An interactive animated web poster and game for Pop Culture roasted fox nut (makhana) snacks.

## Features
- **Interactive Makhana Physics**: Click to pop makhanas with comic onomatopoeia (`POP!`, `CRUNCH!`, `CRISPY!`, etc.) and crunch sound effects.
- **Dynamic Relocation**: When makhanas pop, replacement makhanas dynamically spawn and arrive at completely new locations on screen.
- **Mobile Optimized**: Responsive `100dvh` viewport, proportional makhana scaling, and touch-optimized controls.
- **Color Cycling & Size Beats**: Flavor palette cycling and comic bubble badges.
- **Tech Stack**: React 19, Vite, Tailwind CSS v4, Lucide React, Web Audio API.

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
