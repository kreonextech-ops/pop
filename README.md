# Pop Culture — Roasted Makhana Website

An interactive, high-energy modern website for Pop Culture roasted fox nut (makhana) snacks.

## Features
- **Interactive Hero & Flavour Showcase**: Dynamic scattered assets and flavor switcher (Peri Peri, Cheddar Cheese, Plain Salt).
- **GSAP Scrollytelling**: 6-step Key Health Benefits interactive scroll experience pinned with GSAP and ScrollTrigger.
- **Retro Arcade Mini-Game**: Interactive Fox runner stage.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## Tech Stack
- Next.js (App Router)
- React / Tailwind CSS
- GSAP & ScrollTrigger
- Lucide Icons & Canvas Confetti

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or custom port) with your browser to see the result.
